# Привет, я Рината! 👋
### 🛠️ Инженер сопровождения ПО (L2) / B2B Support 

---

### 🚀 Ключевые компетенции:
* 🔍 **Диагностика и воспроизведение багов (API):** Проверка эндпоинтов в Postman, cURL и DevTools, разбор статус-кодов (200, 4xx, 5xx) и JSON/YAML-пейлоадов, локализация проблем на стороне клиента или бэкенда.
* 📖 **Работа с API-контрактами (OpenAPI 3.0 / Swagger):** Сверка API-запросов и интеграций со спецификацией, поиск невалидных параметров и ошибок маппинга до эскалации на разработку.
* 🗄️ **Верификация данных (SQL):** Написание SQL-запросов для поиска расхождений статусов, проверки транзакций и анализа инцидентов в БД.
* 📊 **Трассировка логики и сбоев:** Построение Sequence-диаграмм (PlantUML / Draw.io) и BPMN-схем для понимания цепочки вызовов и поиска точек отказа в интеграциях.
* 📚 **Базы знаний & Docs-as-Code:** Создание понятных гайдов по траблшутингу, регламентов и инструкций в Confluence / Notion / Markdown (Git, ветки, MR/PR).
