### 🚀 Ключевые компетенции:
- 📖 **API Спецификации & Документация:** Разработка и поддержка OpenAPI 3.0 (Swagger) в JSON/YAML (эндпоинты, схемы, валидация параметров, обработка кодов ошибок).
- 🔍 **Тестирование и верификация:** Ручная проверка эндпоинтов в Postman, подготовка коллекций запросов (200, 4xx, 5xx) для смежных команд.
- 🛠 **Docs-as-Code:** Ведение документации в Markdown внутри репозиториев (Git/GitLab/GitHub), работа с ветками, коммитами и Merge/Pull Requests.
- 📊 **Архитектурные диаграммы:** Построение Sequence-диаграмм в PlantUML для визуализации вызовов между микросервисами.
- 📚 **Базы знаний & Инструкции:** Ведение Confluence, гайды по интеграции, сценарии траблшутинга и регламенты.
